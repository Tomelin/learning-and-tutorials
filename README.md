# Go Stock Analyzer

## Description
This program fetches historical stock data for a specified symbol using the Tiingo API. It then calculates several common technical indicators (EMAs, SMA, RSI), determines the current market trend based on these indicators, and prepares a formatted prompt suitable for analysis by a generative AI model like Google's Gemini. Additionally, if a stock is identified to be in a downtrend, it performs a validation by looking for a significant low price that occurred before the current downtrend began. The final step of calling the AI API is left as a TODO for the user to implement.

## Prerequisites
*   **Go:** Version 1.22.2 or higher (developed with 1.22.2, uses go-talib which required an update to go1.23.9 during `go get`).
*   **Tiingo API Key:** A valid API key from [Tiingo](https://www.tiingo.com) is required to fetch stock data.

## Setup & Installation
1.  **Set Environment Variable:**
    You need to set the `TIINGO_API_KEY` environment variable to your Tiingo API key.
    ```bash
    export TIINGO_API_KEY="YOUR_API_KEY_HERE"
    ```
    Replace `"YOUR_API_KEY_HERE"` with your actual Tiingo API key. For persistent storage, add this line to your shell's configuration file (e.g., `.bashrc`, `.zshrc`).

2.  **Clone the Repository (if applicable):**
    If you have cloned this project from a repository, navigate to the project root directory (`stockanalyzer/`).

3.  **Tidy Dependencies:**
    The necessary dependencies (`github.com/markcheno/go-quote` and `github.com/markcheno/go-talib`) are listed in `go.mod`. Running `go mod tidy` will ensure they are correctly downloaded and the `go.sum` file is up to date.
    ```bash
    go mod tidy
    ```

4.  **Build the Executable:**
    Compile the program to create an executable file.
    ```bash
    go build
    ```
    This will create an executable named `stockanalyzer` (or `stockanalyzer.exe` on Windows) in the project root directory.

## Running the Program
After a successful build, you can run the program using:
```bash
./stockanalyzer
```
Alternatively, you can run it directly without building using:
```bash
go run main.go
```
The program will output the fetched data, calculated indicators, determined trend, validation results (if applicable), and the prompt for Gemini analysis to the console.

## How it Works
1.  **Data Fetching:** The application fetches daily historical stock data (Open, High, Low, Close, Volume, Date) from Tiingo for the predefined stock symbol and date range.
2.  **Indicator Calculation:** It calculates the following technical indicators using the closing prices:
    *   Exponential Moving Average (EMA) for periods 7, 21, and 49.
    *   Simple Moving Average (SMA) for a 50-period.
    *   Relative Strength Index (RSI) for a 14-period.
3.  **Trend Determination:** The trend is determined based on the relative positions of EMA(7), EMA(21), and EMA(49). The `DetermineHistoricalTrend` function calculates the trend for each period where EMAs are valid, and `DetermineTrend` returns the most recent trend.
    *   **Uptrend:** If EMA(7) > EMA(21) AND EMA(21) > EMA(49).
    *   **Downtrend:** If EMA(7) < EMA(21) AND EMA(21) < EMA(49).
    *   **Undetermined:** Otherwise, or if there's insufficient data.
4.  **Previous Low Validation (for Downtrends):** If the stock is currently in a "downtrend", the program attempts to find the most recent significant low price that occurred *before* the current downtrend began. This is done by the `FindPreviousLowBeforeDowntrend` function, which analyzes the historical trends and low prices. It then compares this historical low to the current price and prints a validation message. This can provide context, for example, by indicating if the current price is approaching or has breached a previous support level.
5.  **Gemini Analysis Prompt:** The program prepares a detailed text prompt containing the stock symbol, latest price, key indicator values, and the determined trend. This prompt is designed to be fed into a generative AI model like Gemini for market insights or buy/sell/hold recommendations.
    *   **TODO:** The actual call to the Gemini API (or any other AI service) is not implemented. Users need to add their own code to send this prompt to an AI model and process the response. This is marked with a `// TODO:` comment in `main.go`.

## Customization
*   **Stock Symbol and Dates:** The default stock symbol (`AAPL`), `startDate`, `endDate`, and indicator periods (`rsiPeriod`, `smaPeriod`) are defined at the beginning of the `main()` function in `main.go`. You can modify these values to analyze different stocks or timeframes.
*   **Indicator Logic:** The logic for trend determination and the set of indicators used can be modified in the `stockanalyzer/indicators.go` file.
